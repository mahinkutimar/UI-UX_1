# Beauty Bliss 💄✨

Beauty Bliss is a modern beauty and cosmetics shopping UI/UX project inspired by Nykaa.  
This project focuses on creating an elegant, user-friendly, and responsive shopping experience for beauty lovers.

---

## 📌 Features
- Modern UI Design
- Beauty Product Browsing
- Wishlist & Cart UI
- Smooth Navigation
- Responsive Mobile Design
- Attractive Product Cards

---

## 🎨 Tools Used
- Figma
- Canva
- Adobe XD

---

## 📱 Screens Included
- Splash Screen
- Login & Registration
- Home Page
- Product Details
- Cart Page
- Wishlist
- Checkout Page
- User Profile

---

## 🎯 Project Goal
The goal of Beauty Bliss is to improve the online beauty shopping experience with a clean and visually appealing interface.
